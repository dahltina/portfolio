# Tina Dahl — Designer & Frontend Developer

I'm Tina, a designer and frontend developer based in Oslo. I work across web design, visual identity and typography, bringing an interest in layout, colour and detail into the websites I build.

This portfolio brings together personal and student projects, from brand concepts and type design to websites developed with React or HTML, CSS and JavaScript.

The portfolio itself is built with **Astro, TypeScript, CSS and JavaScript** and deployed through **Netlify**.

Astro generates static HTML at build time. The site needs no application server, and its custom interactions use browser JavaScript.

## Run locally

Use Node.js 22.23.4 or newer.

```sh
npm install
npm run dev
```

To create and preview a production build:

```sh
npm run build
npm run preview
```

`npm run check:links` checks internal links and anchors in the generated `dist/` output after a build.
